# SANTAGIFTS 🎁

Intercambio de regalos (amigo secreto) para familia y amigos.

- **Next.js** (App Router, TypeScript, Tailwind)
- **Supabase**: base de datos en el esquema `santagifts`, inicio de sesión con Google y código por correo
- Sugerencias de regalos de **Mercado Libre** según el presupuesto del evento (Amazon después)

## Correr en tu compu

```bash
cp .env.example .env.local   # y llena tus llaves de Supabase
npm install
npm run dev
```

Abre http://localhost:3000
